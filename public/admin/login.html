IT Service Desk
SECURE AUTHENTICATION GATEWAY
1.1 Admin: Login (POST /admin/login)
เข้าสู่ระบบด้วยสิทธิ์ผู้ดูแลระบบ Token จะถูกเก็บใน data.token
บัญชีทดสอบ:
2.1 User: Login (POST /api/auth/local)
เข้าสู่ระบบด้วย identifier (อีเมลหรือ Username) เพื่อรับ jwt
เลือกบัญชีทดสอบ:
2.2 User: Signup (POST /api/auth/local/register)
สร้างผู้ใช้งานใหม่พร้อมรับ JWT Token ใช้งานได้ทันที
1.2 Admin: Signup (POST /admin/register-admin)
สร้างบัญชี Super Admin คนใหม่ของระบบ
2.3 User: Forgot Password (POST /api/auth/forgot-password)
ระบบจะสร้าง code สำหรับนำไปตั้งรหัสใหม่
1. ขอรหัสรีเซ็ต (Forgot Password)
2. ตั้งรหัสผ่านใหม่ (Reset Password)
