System Users & RBAC Roles

รายชื่อผู้ใช้งานและบทบาทในระบบ IT Service Desk

ชื่อ-นามสกุล / Username อีเมล (Email) สิทธิ์การใช้งาน (Role) แผนก (Department) สิทธิ์การทำงาน
Admin User admin@example.com ADMIN Management Full SuperAdmin Permissions
Somchai TechSupport support@servicedesk.local IT_SUPPORT IT Operations Manage & Resolve Tickets
Employee User employee@example.com EMPLOYEE General Create & View Own Tickets
Wichai Accountant employee1@servicedesk.local EMPLOYEE Finance Create & View Own Tickets
🔐 เข้าสู่ระบบ & จัดการบัญชี
1.1 Admin Login: POST /admin/login
ส่ง email, password, rememberMe เพื่อรับ token ใน data.token
ตัวอย่าง:
2.1 User Login: POST /api/auth/local
ส่ง identifier (อีเมลหรือ Username) และ password เพื่อรับ jwt
เลือกบัญชีทดสอบ:
2.2 User Signup: POST /api/auth/local/register
สร้างผู้ใช้งานทั่วไป พร้อมรับ jwt ทันที
1.2 Admin Signup: POST /admin/register-admin
สร้างผู้ดูแลระบบ (Super Admin) ส่ง firstname, lastname, email, password
2.3 User Forgot Password: POST /api/auth/forgot-password
รับ code เพื่อนำไปใช้รีเซ็ตรหัสผ่านใน 2.3.1
ขั้นตอนที่ 1: ขอรหัสรีเซ็ต (Forgot Password)
ขั้นตอนที่ 2: ตั้งรหัสผ่านใหม่ (Reset Password)
➕ แจ้งซ่อม / สร้างตั๋วใหม่
➕ สร้างหมวดหมู่ปัญหาใหม่
